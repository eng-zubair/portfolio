# Zubair Ahmad Chohan — Portfolio

A personal portfolio built with React, Tailwind CSS, Framer Motion and Vite.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build` and preview it with `npm run preview`.

## Update portfolio content

- Edit profile, project, skills, experience and training details in `src/data.js`.
- Replace `public/Zubair_Ahmad_Chohan_CV.pdf` to update the downloadable CV.
- Adjust colors, layout and responsive styles in `src/index.css`.
